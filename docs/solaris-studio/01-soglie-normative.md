# Soglie normative chiave

Punti di potenza che cambiano la configurazione dell'impianto (e il preventivo).

| Soglia | Cosa cambia |
|---|---|
| **≤ 6 kW monofase** | Impianto standard monofase. Nessun obbligo aggiuntivo. CEI 0-21 base. |
| **> 11,08 kW** | **SPI esterno obbligatorio** (dispositivo di interfaccia separato dall'inverter). CEI 0-21 §9.5.1. |
| **≥ 20 kWp** | **VVF + licenza di officina elettrica + PAS + telecontrollo**. Regime "industriale". |
| **> 100 kWp** | Connessione in MT (CEI 0-16), cabina di trasformazione. **Fuori dal perimetro Solaris.** |

## Calcolo dei pannelli (450 W)
`pannelli = kWp × 1000 / 450`, sempre arrotondato all'intero superiore.
Esempio: 12 kWp → 12000 / 450 = 26,7 → **27 pannelli**.
